The bank and the ledger never agree.

Two-pass matching: exact first, then within tolerance, then exceptions with a stated reason.

Pass one needs the exact reference and amount. Pass two accepts a normalised reference inside an amount and date tolerance, because feeds disagree about spacing, casing and value dates.

What fails both becomes an exception with a reason, never a silent drop. The other tools on the board are the same job in a different part of the business.

Then solve it in fewer steps.

Newton-Raphson with a bisection safeguard, checked against a round-trip through Black-Scholes before it runs. Iterations, not milliseconds: at this size wall clock is dominated by timer resolution and JIT warm-up, while the iteration count is exact. The worst case barely moves: warming the start cuts the mean, not the tail, because the tail is the first strike in the chain, which has no previous answer to inherit.
